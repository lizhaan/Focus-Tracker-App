# Attention Tracker

Десктоп-застосунок для трекінгу фокусу через вебкамеру: визначає, чи
користувач дивиться на робочий монітор, показує плашку "Фокус втрачено" і
ставить Pomodoro на паузу при відволіканні, зберігає історію сесій.
Навчальний проєкт з ООП.

## Документи (читати перед роботою)

- `docs/PROJECT_PLAN.md` — ідея, вимоги, архітектура, класи, структура тек,
  схема БД, етапи, тести. **Розділ 13 — обовʼязкові правила.**
- `docs/MATH.md` — усі формули, пороги, калібрування, машина станів.
  **Джерело правди**: реалізовувати дослівно; при суперечності з іншими
  документами — правий `MATH.md`.

## Стек

Python 3.11/3.12 · MediaPipe FaceLandmarker (Tasks API) · OpenCV · NumPy ·
PySide6 · pyqtgraph · SQLite · pytest

## Команди

```bash
pip install -r requirements.txt
python -m attention_tracker.main     # запуск
pytest                               # тести — мають проходити після кожної зміни
```

## Ключові правила

- Працювати **по одному кроку** з `PROJECT_PLAN.md` §11. Після кроку —
  тести для нього, `pytest` зелений, короткий звіт що зроблено.
- **Один робочий монітор.** Кілька моніторів — поза обсягом, не реалізовувати.
- Логіка (`vision/`, `focus/`, `calibration/`, `storage/`) — **без Qt**, час
  передається явно як `now: float` (`time.monotonic()`). Qt тільки в
  `workers/` і `ui/`.
- Час — у секундах, **не в кадрах**. Кадр **не дзеркалити** перед обробкою.
  Геометрія landmark-ів — **у пікселях**.
- SQLite — тільки з головного потоку. UI — тільки з головного потоку.
- Відео/кадри **ніколи не зберігати** і не передавати.
- Усі числові параметри — в `config.py`, без магічних чисел у коді.
- Не писати в коді посилань на розділи документів (`MATH §…`, `PROJECT_PLAN §…`,
  `FR-…`) — ні в docstring-ах, ні в коментарях.
- Type hints, `dataclass` для даних, `Enum` для станів.
- Невдала детекція обличчя — це `valid=False`, а не виняток.
- Неоднозначність або щось нереалізовне — **спитати**, не вигадувати.
- Не змінювати `docs/` без прохання; якщо документ треба оновити — запропонувати.
